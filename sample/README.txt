# Sample XMind Files

This directory is for storing sample XMind files that can be used for testing the mindmap viewer.

To use a sample file:
1. Download a sample XMind file from the official XMind website or create your own using XMind
2. Place the .xmind file in this directory
3. Use the file input in the webpage to load the file

Note: Since .xmind files are binary files, they cannot be included directly in this text-based repository. You'll need to create or download them separately.
