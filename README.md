# XMind Mark Mindmap Viewer

A simple web application that allows users to view and interact with mindmaps using the XMind Mark library.

## Features

- Load and display XMind files (*.xmind)
- View a sample mindmap without uploading a file
- Interactive mindmap with zoom and pan functionality
- Customized mindmap appearance

## How to Use

1. Clone this repository
2. Install dependencies with `npm install`
3. Start the application with `npm start`
4. Open your browser to the local server URL displayed in the terminal

## Usage

- Click "Load Sample Mindmap" to view a pre-defined example
- Use the file input to select and load your own XMind file
- Interact with the mindmap:
  - Zoom in/out using the mouse wheel
  - Pan by clicking and dragging

## Technology

This project uses:
- [XMind Mark](https://github.com/xmindltd/xmindmark) - A JavaScript library for rendering mindmaps
- HTML5, CSS3, and JavaScript (ES6+)
